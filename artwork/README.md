# アイコンの出自

## 配布されるアイコンは `ide/icons/sprout68k.svg`

タブアイコンと PWA アイコンは、この SVG を手で書いたものと、そこから
ラスタライズした PNG（16/32/192/512）です。**画像生成モデルの出力を
そのまま配布物にはしていません。**

理由: タブアイコンは 16px で表示され、生成したラスタ画像を 16px へ縮めると
輪郭が潰れます。SVG なら小さくても形が保てます。

16px での見え方は推測せず実測しました: 前景 26.6%、8近傍の連結成分1個
（=バラバラに分断されていない）、bbox 12x13px、背景 `#111827` に対する
最小コントラスト比 10.18:1。

## `sprout68k-generated.png` はデザインの参考

`artwork/sprout68k-generated.png` は**画像生成モデルが描いたもの**で、
双葉のかたちを決めるための参考として残しています。配布物には含まれません。

## 他者のブランド資産は使っていない

Neko Project の猫、シャープのロゴ、既存アイコンの改変などは一切使わず、
双葉のモチーフからゼロで起こしています。
